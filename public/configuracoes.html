Provedores comuns

Host e porta de referência de quem usa Gmail, Outlook ou SendGrid pra disparo transacional. Confirme com quem administra o e-mail da empresa.

Gmail / Google Workspace smtp.gmail.com · porta 587 (TLS) · usuário = e-mail completo · senha = senha de app (exige verificação em 2 etapas)
Outlook / Microsoft 365 smtp.office365.com · porta 587 (STARTTLS) · usuário = e-mail completo
SendGrid smtp.sendgrid.net · porta 587 · usuário = apikey (literal) · senha = sua API key do SendGrid
